## Разработка

### Требования
Для установки и запуска проекта, необходим [NodeJS](https://nodejs.org/) v8+ [Angular](https://angular.dev/)v20+  .

### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
$ npm i
```

### Запуск Backend
Чтобы запустить сервер, перейдите в папку \Backend\App\WebApi выполните команду:
```sh
dotnet run
```

### Запуск фронта
Чтобы запустить frontend, выполните команду: 
```sh
ng serve
```
